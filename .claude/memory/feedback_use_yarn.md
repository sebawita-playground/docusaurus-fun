Always use `yarn` for package management commands (install, uninstall, add, etc.), never `npm`.

**Why:** User preference for this project.

**How to apply:** Replace any `npm install`, `npm uninstall`, `npm run` etc. with `yarn add`, `yarn remove`, `yarn` etc.
